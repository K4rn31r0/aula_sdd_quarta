# 04: Copiar e reutilizar listas

**What to build:** copiar listas antigas e reutilizar ou limpar o progresso de compras em operações completas pela interface.

**Blocked by:** 02: Gerenciar listas.

**Status:** done

- [x] Uma pessoa pode copiar uma lista existente.
- [x] A cópia mantém todos os itens da origem, mas inicia todos como não comprados.
- [x] A cópia não altera nem exclui a lista original.
- [x] O primeiro nome disponível usa `Nome (cópia)` e os seguintes usam `Nome (cópia 2)`, `Nome (cópia 3)` e assim por diante.
- [x] Uma pessoa pode reutilizar uma lista após confirmar.
- [x] Reutilizar desmarca todos os itens sem criar, renomear ou remover itens.
- [x] Uma pessoa pode limpar os itens comprados após confirmar.
- [x] Limpar comprados remove somente itens marcados e preserva os não comprados.
- [x] Operações sobre uma lista inexistente não criam nem corrompem dados.
- [x] Testes do módulo de regras cobrem nomes sequenciais de cópias, reutilização, limpeza e comportamento de listas inexistentes.

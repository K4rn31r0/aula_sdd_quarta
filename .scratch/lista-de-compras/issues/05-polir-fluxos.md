# 05: Finalizar interface e feedback

**What to build:** concluir a experiência mobile-first com feedback, estados vazios, cancelamento e confirmações consistentes.

**Blocked by:** 02: Gerenciar listas; 03: Gerenciar itens da lista; 04: Copiar e reutilizar listas.

**Status:** done

- [x] A interface utiliza CSS próprio, layout mobile-first e HTML semântico renderizado pelo servidor.
- [x] Não há biblioteca de componentes nem framework JavaScript.
- [x] Formulários de criação, renomeação e edição oferecem ações de salvar e cancelar.
- [x] Cancelar volta à tela anterior sem alterar dados persistidos.
- [x] Exclusão de lista, reutilização e limpeza de comprados usam confirmação.
- [x] Remoção individual de item continua imediata.
- [x] Criação, renomeação, cópia, reutilização e exclusão exibem mensagens breves de sucesso.
- [x] A tela inicial vazia contém orientação e ação para criar uma lista.
- [x] A tela de uma lista vazia contém orientação e ação para adicionar um item.
- [x] Conflitos e erros de validação são exibidos próximos ao campo ou formulário relevante.
- [x] Uma pessoa consegue criar uma lista, adicionar itens, marcar a compra e reutilizar a lista em um fluxo completo de navegador.
- [x] Os testes existentes continuam verdes após a interface ser concluída.
